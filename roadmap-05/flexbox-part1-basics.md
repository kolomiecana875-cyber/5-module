# Flexbox: Основи та термінологія

## 1. Вступ до Flexbox

Flexbox (Flexible Box Layout) - це потужний інструмент CSS для створення адаптивних та гнучких макетів. Він дозволяє ефективно розміщувати, вирівнювати та розподіляти простір між елементами в контейнері, навіть коли їх розміри невідомі або динамічні.

### Переваги Flexbox:

- Спрощене вертикальне та горизонтальне вирівнювання
- Адаптивний дизайн без медіа-запитів
- Гнучкий розподіл простору
- Зміна порядку елементів без зміни HTML

## 2. Основна термінологія

```
┌───────────────────────┐
│      Flex Container   │
│  ┌─────────────────┐  │
│  │  Flex Item      │  │
│  │                 │  │
│  └─────────────────┘  │
│                       │
│ Main Axis →           │
│ ↓ Cross Axis          │
└───────────────────────┘
```

- **Flex-контейнер**: Елемент, до якого застосовано `display: flex`
- **Flex-елементи**: Прямі нащадки flex-контейнера
- **Головна вісь**: Основний напрямок розташування елементів (визначається властивістю `flex-direction`)
- **Поперечна вісь**: Перпендикулярна до головної осі

## 3. Створення flex-контейнера

```css
.container {
  display: flex; /* або inline-flex */
}
```

## 4. Основні властивості контейнера

### flex-direction

Визначає напрямок головної осі:

```css
.container {
  flex-direction: row; /* за замовчуванням: зліва направо */
  /* Інші значення:
     row-reverse - справа наліво
     column - зверху вниз
     column-reverse - знизу вгору */
}
```

### flex-wrap

Визначає, чи будуть елементи переноситись на новий рядок:

```css
.container {
  flex-wrap: nowrap; /* за замовчуванням: всі елементи в одному рядку */
  /* Інші значення:
     wrap - перенесення на новий рядок
     wrap-reverse - перенесення у зворотному порядку */
}
```

### gap

Задає відступи між елементами:

```css
.container {
  gap: 10px; /* однаковий відступ по вертикалі та горизоталі */
  /* або */
  gap: 10px 20px; /* відступ по вертикалі та горизонталі */
  /* також можна вказати окремо */
  row-gap: 10px;
  column-gap: 20px;
}
```
