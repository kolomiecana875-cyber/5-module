# Flexbox: Властивості вирівнювання та елементів

## 1. Властивості вирівнювання контейнера

### justify-content
Вирівнює елементи вздовж головної осі:

```css
.container {
  justify-content: flex-start; /* за замовчуванням */
  /* Інші значення:
     flex-end - вирівнювання в кінець осі
     center - вирівнювання по центру
     space-between - рівномірний розподіл з крайніми елементами по краях
     space-around - рівномірний розподіл з половинними відступами на краях
     space-evenly - рівномірний розподіл з однаковими відступами між усіма елементами */
}
```

### align-items
Вирівнює елементи вздовж поперечної осі:

```css
.container {
  align-items: stretch; /* за замовчуванням - розтягнути на всю висоту/ширину */
  /* Інші значення:
     flex-start - вирівнювання на початок поперечної осі
     flex-end - вирівнювання в кінець поперечної осі
     center - вирівнювання по центру
     baseline - вирівнювання по базовій лінії тексту */
}
```

### align-content
Вирівнює рядки flex-елементів, коли є кілька рядків (з flex-wrap: wrap):

```css
.container {
  align-content: stretch; /* за замовчуванням */
  /* Інші значення:
     flex-start - рядки притиснуті до початку
     flex-end - рядки притиснуті до кінця
     center - рядки по центру
     space-between - рядки розподілені рівномірно з першим та останнім по краях
     space-around - рядки розподілені рівномірно з половинними відступами на краях */
}
```

## 2. Властивості flex-елементів

### flex-grow
Визначає здатність елемента розтягуватися відносно інших елементів:

```css
.item {
  flex-grow: 0; /* за замовчуванням (не розтягується) */
  /* Числові значення: 1, 2, ... - відносні пропорції розтягування */
}
```

Значення > 0 дозволяє елементу збільшуватись, щоб заповнити доступний простір. Якщо у всіх елементів flex-grow: 1, вони займатимуть однаковий простір. Якщо один елемент має flex-grow: 2, а інші по 1, то перший займе вдвічі більше вільного простору.

### flex-shrink
Визначає здатність елемента стискатися:

```css
.item {
  flex-shrink: 1; /* за замовчуванням (стискається) */
  /* Числові значення: 0 (не стискається), 2, 3, ... (стискається сильніше) */
}
```

### flex-basis
Встановлює базовий розмір елемента вздовж головної осі:

```css
.item {
  flex-basis: auto; /* за замовчуванням (розмір вмісту) */
  /* Можливі значення:
     <довжина> (px, %, em, rem)
     0 (початковий розмір нуль) */
}
```

### flex (скорочення)
Скорочений запис для flex-grow, flex-shrink і flex-basis:

```css
.item {
  flex: 0 1 auto; /* за замовчуванням (grow shrink basis) */
  
  /* Поширені комбінації: */
  flex: 1; /* flex: 1 1 0% - розтягується, стискається, базова ширина 0 */
  flex: auto; /* flex: 1 1 auto - розтягується, стискається, базова ширина auto */
  flex: none; /* flex: 0 0 auto - не розтягується, не стискається */
  flex: 0 auto; /* flex: 0 1 auto - не розтягується, але стискається */
  flex: 1 200px; /* flex: 1 1 200px - розтягується, стискається, базова ширина 200px */
}
```

### align-self
Перевизначає align-items для окремого елемента:

```css
.item {
  align-self: auto; /* за замовчуванням (наслідує align-items) */
  /* Інші значення:
     flex-start | flex-end | center | baseline | stretch */
}
```

### order
Визначає порядок відображення flex-елемента:

```css
.item {
  order: 0; /* за замовчуванням */
  /* Від'ємні та додатні цілі числа змінюють порядок елементів */
}
```

Елементи з меншим значенням order відображаються раніше. Елементи з однаковим значенням order відображаються в порядку HTML.

## 3. Як це все працює разом

Коротка шпаргалка порядку роботи алгоритму Flexbox:

1. Flex-контейнер визначає напрямок і можливість перенесення елементів
2. Flex-елементи отримують початковий розмір на основі їх вмісту або flex-basis
3. Якщо елементи не поміщаються, вони стискаються згідно flex-shrink
4. Якщо залишається вільний простір, елементи розтягуються згідно flex-grow
5. Елементи вирівнюються відповідно до justify-content і align-items
